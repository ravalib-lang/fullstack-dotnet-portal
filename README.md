# Full-Stack .NET Learning Portal

A hands-on learning project to practice the topics from my .NET learning tracker using a small Member Portal application.

## Goal

Build the application step by step so each concept can be explained with working code instead of only definitions.

## Planned Architecture

```text
Angular UI
   ↓
Component
   ↓
Angular Service
   ↓
HttpClient / RxJS
   ↓
HTTP Interceptor
   ↓
ASP.NET Core Middleware
   ↓
Controller
   ↓
Service
   ↓
Repository
   ↓
EF Core / Dapper
   ↓
SQL Server
```

## Topics Covered

### Backend
- REST APIs and backend request flow
- Controller, Service, Repository
- EF Core and Dapper
- SQL Server
- REST vs gRPC
- Middleware
- Dependency Injection
- Configuration
- Async/Await
- Exception Handling
- Validation
- JWT Authentication
- Authorization

### Frontend
- Angular architecture
- TypeScript
- Components
- Data Binding
- Angular Services
- HttpClient
- RxJS and Observables
- Reactive Forms
- Routing
- Route Guards
- HTTP Interceptors

## Learning Approach

Each feature will be added in a separate, meaningful commit so the Git history shows the learning progression.

This project uses sample data only and does not contain proprietary project code or production data.
